Upload Wafers

Bring your own wafer maps. Files are validated on the server and previewed here; then inspect a single wafer or replay them all as a lot with drift detection and a cost decision.

Supported formats

Encoding: 0 = no die (background) · 1 = pass die · 2 = fail die. Any grid size; maps are resized to 64 × 64.
JSON

A 2-D array, {"wafer": [[…]]}, a list of those, or {"wafers": [{"wafer_id": "W1", "wafer": [[…]]}, …]}.

CSV / TXT

One row per line, values separated by commas, spaces or tabs. Several wafers: separate blocks with a blank line; a line like # W1 names the next wafer.

NPY / NPZ

A 2-D array (one wafer) or a 3-D stack (N, H, W). Pickled object arrays are rejected.

Images

A rendered wafer map in three colours. Background is taken from the image border, the warmer colour is read as fail. Always check the preview.
